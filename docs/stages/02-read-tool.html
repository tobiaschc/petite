Base agent

2. Read tool

View this stage's code on GitHub →

An LLM can't touch a filesystem by default — it only produces text. A "tool" is just a JSON schema describing a function, sent alongside the prompt, that the model can ask to have called. This stage advertises exactly one: Read. Still a single round trip — the model asks, you call it, you print the result and exit. No loop yet, because the point here is purely "the model can ask for something it doesn't have."

Your task

  1. Add a Read tool to the request's tools array: a JSON schema with one required file_path string.
  2. When the model's response includes a tool call for it, execute it yourself (read the file) and print the raw contents. Still a single round trip — don't loop yet.

Try it

Run this stage's own code:

just stage 2
cd .stages/02
echo "hello from petite" > test.txt
just run "Show me what's inside test.txt. Respond with only the file contents, no backticks."

Expect: hello from petite
