12. Bundled scripts (level 3)

View this stage's code on GitHub →

A skill folder can hold more than SKILL.md — scripts/, references/, assets/ — and none of it costs any context until the body explicitly points at it. That's level 3: a two-line body can reference a two-hundred-line script, and neither the script nor its output enters the conversation until the model actually runs it. The one wrinkle is that the body names its files with paths relative to its own folder (scripts/sha256.sh), while the agent runs from the project root. Telling the model which folder that is turns out not to be enough — models often run the relative path as-is and get "file not found" — so before a body reaches the model, its bundled paths are rewritten to paths from the project root (.petite/skills/badger/scripts/sha256.sh).

Your task

  1. Let a skill folder hold scripts/, references/, or assets/ alongside SKILL.md — none of it loads into context unless the body names it.
  2. Before a resolved body reaches the model, rewrite its bundled paths (scripts/, references/, assets/) to paths from the project root, and prefix a header naming the skill's folder (Skill: name (located at path)).
