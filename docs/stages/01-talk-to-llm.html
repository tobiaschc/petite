Base agent

1. Talk to an LLM

View this stage's code on GitHub →

The smallest possible agent isn't an agent at all: one prompt in, one response out, no memory, no tools. Before adding any of that, there has to be something that talks to an LLM API at all. Everything else in this project is this call, wrapped in more structure.

Only the bold arrows leave your machine, over the internet (HTTPS). The model never reads your files or runs anything: it can only ask, and petite does the work locally.

Your task

  1. Send a single prompt to an OpenAI-compatible chat completions endpoint.
  2. Print the response content. No tools, no loop — one request in, one answer out.

Try it

Run this stage's own code (after just setup), from the repo root:

just stage 1
cd .stages/01
just run "Please compute 2 + 3. Respond with only a number."

Expect: 5

.stages/01 is a git worktree: your checkout stays on main, so just keeps working there. Or browse it on GitHub; just clean-stages removes the worktrees.
