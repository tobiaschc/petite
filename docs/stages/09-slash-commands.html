Skills

9. Slash commands (level 2)

View this stage's code on GitHub →

Level 1 tells the model a skill exists; level 2 is the first way to actually load one. When a prompt starts with /name, that's resolved directly to a folder and its SKILL.md body replaces the raw prompt as the user message — no model judgment involved, the user named the skill explicitly. Every other skill stays at level 1, which matters: if two full bodies land in context at once with conflicting instructions, the model has no way to know which one to follow.

Your task

  1. When a prompt starts with /name, resolve name to a skill folder, read its body (everything after the closing ---), and send that as the user message instead of the raw prompt.
  2. Every other discovered skill stays at level 1 (name + description only) — don't load any other body.

Try it

Run this stage's own code:

just stage 9
cd .stages/09
mkdir -p .petite/skills/otter && cat > .petite/skills/otter/SKILL.md <<EOF
---
name: otter
description: Reports where the project's otter lives.
---
Respond with exactly one word: river
EOF
just run "/otter"

Expect: river — exactly what the skill's body told the model to say, since the model only sees that body as its instruction
